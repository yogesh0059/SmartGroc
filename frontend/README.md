# 🛒 SmartGroc

SmartGroc is a modern grocery shopping web application that allows users to browse products, manage their cart, and enjoy a smooth and responsive shopping experience. The project is designed with performance and simplicity in mind.

---

## 🚀 Features

* 🛍️ Browse grocery products
* ➕ Add items to cart
* ❌ Remove items from cart
* 🔄 Real-time cart updates
* 📱 Fully responsive design
* ⚡ Fast and optimized performance

---

## 🛠️ Tech Stack

* **Frontend:** React + TypeScript
* **Build Tool:** Vite
* **Styling:** Tailwind CSS / ShadCN UI
* **State Management:** React Hooks
